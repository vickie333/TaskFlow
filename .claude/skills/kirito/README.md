# Kirito

Kirito is a reserved, strategic, anime-inspired person layer for Goza. It provides
temperament and framing, not a language or nationality.

Use it alone:

```text
/goza kirito
```

Or compose it with a nationality:

```text
/goza kirito peruano
```

The composition keeps Kirito's calm, tactical framing and adds the selected nationality
layer's language and register.
